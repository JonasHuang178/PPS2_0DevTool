# Design

## Decisions

**一、`Filter` 的內容是一個四列的表單，不是兩塊並排。**

```
      Author  [候選清單                  ]
 Starts with  [__________________________]
   Ends with  [__________________________]
    Contains  [__________________________]
```

標籤右對齊在同一欄、輸入控件起於同一個位置。先前兩塊並排時有兩種對齊方式，而人眼會先看到
那個落差，再看到內容。

代價是高度：候選清單自成一列之後，群組比先前高。接受 —— 群組本來就預設收合，展開是使用者
主動要求看它的時候。

**二、選取時的連結色靠「自己畫文字」保住，不是靠 palette。**

試過只在委派的 `initStyleOption()` 裡把 `QPalette::HighlightedText` 設成連結色 —— **沒有用**，
量出來仍是外殼的深藍。原因是外殼的選取樣式是一條樣式表規則，而 `QStyleSheetStyle` 在畫項目時
會用規則裡的 `color` 覆寫 palette，覆寫發生在委派交出 option 之後。

所以委派在 `paint()` 裡讓樣式畫背景與選取高亮，但**把文字清空**不讓它畫，然後自己畫文字。
這是唯一能蓋過那條規則的方式，而且範圍只有標題那一欄。

這個順序不能顛倒：先讓樣式畫完背景與焦點框，文字才疊得上去。

**三、截斷與對齊沿用 option 上的值，不自己訂。**

`textElideMode` 與 `displayAlignment` 由檢視與項目決定。寫死在委派裡的話，標題欄會與其餘四欄
不一致，而症狀是「只有標題欄的省略號出現得比較早」—— 看起來像欄寬算錯，不像委派寫錯。

**四、顏色讀項目自己的 `ForegroundRole`，不寫死。**

委派因此不必知道連結色是什麼，換色只要改填資料的那一邊。

## Risks / Trade-offs

**接手了文字的繪製，就接手了它的細節。** 省略號、對齊、字型都改由委派負責。已經以實際畫面
確認過三種情況：未選取、選取、標題過長而截斷。但日後若在標題欄加上圖示或勾選方塊，繪製那
一段要跟著處理 —— 目前那一欄只有文字。

**`Filter` 展開時更高，表格更矮。** 這是選這個配置換來的，不是副作用。
