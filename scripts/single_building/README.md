# Single Building

從來源樹挑 `.cpp` 寫進暫存設定檔。四支入口腳本與這個功能專屬的定義（`__init__.py`）。

這個功能**沒有報告可以承載版號**，所以名稱與版號記在每支入口腳本開頭的診斷輸出裡
（console 第一行）。使用方式見 [`docs/user-guide.md`](../../docs/user-guide.md)。

## 版本記錄

`FEATURE_VERSION`（`__init__.py`）。版號規則見
[`docs/contributing.md`](../../docs/contributing.md) 的「版號」一節。

| 版號 | 日期 | 說明 |
|---|---|---|
