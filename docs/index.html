這個站台發布自 add-ai-analysis-gitlab-mr 分支的 /docs 目錄。
分支合併時有兩件事要做：在 repo 的 Settings → Pages 改指向 main； 把所有指向 GitHub 的連結裡的分支名換成 main —— 那些連結散在這一頁與四份圖解頁， 用 grep -rn 'add-ai-analysis-gitlab-mr' docs/ 一次找得到。

參考文件連到 github.com 而不是這個站台，是因為站台關掉了 Jekyll（否則 _doc.css 這種底線開頭的檔案不會被發布），而關掉之後 .md 在站台上是純文字。GitHub 把 markdown 渲染得比任何東西都好。
