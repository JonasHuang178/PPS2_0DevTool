你要做的事

選一個專案，挑一支 MR，按下去

1
在 Repository 清單點一個專案
這份清單來自設定檔，一打開就在那裡。只能選一個。
2
按 Merge Request 區的重新整理
清單不會自己出現 —— 每次取得都是一次網路請求，所以等你開口。 預設只拿「還沒關閉的」和「最近 7 天建立的」。
3
在表格裡點一支 MR
也只能選一個。想先看看它長什麼樣，連按兩下標題會開 GitLab 頁面。
4
（可有可無）勾 Add Debug file
勾了就把中間產物留在你指定的資料夾，想知道每一步各自產出什麼時用。 不勾也完全跑得完。
AI Analysis
按下去，然後等。中間會有一個對話框擋住主視窗，
上面寫著現在跑到第幾步。想停就按它的取消。

按下去之後

它會跑五步，一步接一步

任何一步失敗就整條停下來，並告訴你是第幾步、為什麼。 畫面上的東西完全不會變，沒有東西需要你收拾。

1
去 GitLab 抄下那支 MR 的描述要連線
如果上一輪已經把 AI 分析貼回去過，那一段會被扣掉 —— 否則 AI 會對自己上次的輸出再分析一次。
2
看看這支 MR 有沒有單號、是什麼種類要連線
多半從標題的方括號抽，例如 [PPS-1234][Bug] 修正重試上限 會抽出單號 PPS-1234、種類 bug。
3
把差異交給 AI，問它改了什麼要錢、要等
五步裡唯一要花錢、唯一會等到分鐘級的一步。 檔案太多的話只送得進一部分 —— 報告會老實說少了哪些。
4
去那張單子上找別人做的 code review要連線
找得到就把風險評估表抓進報告。沒有單號、單號無效、 或單子上沒掛那份附件 —— 都算正常，報告裡就少那一段而已。
5
把前面四步的東西拼成一份 markdown不連線
純排版，不再問任何人。跑完就彈出結果視窗。

報告長什麼樣

固定五塊，從上到下

# Original Description
MR 原本的描述，原封不動。
# AI 分析結果
Summary 幾句話講這支 MR 在做什麼。
Code Changes 逐個檔案講改了什麼、為什麼，diff 收在可展開的區塊裡。
## 詳細資料
只在真的用到單子時出現
一行連到那張 JIRA 單。
# 分析涵蓋範圍
「共 90 個檔案，送進分析 21 個，AI 回報了 3 個。」
少了什麼它會自己說 —— 這一段就是為了讓你不用猜。
# Code Review 報告
只在找得到那份附件時出現
別人做的風險評估表，加上日期、作者、原件連結。
出處（最後一行小字）
哪一套邏輯、哪一版腳本、問了哪個 AI。
報告被貼到別處之後，靠這一行知道它是誰產的。

第一次最常卡住的地方

四個「它壞了嗎」其實都不是壞了

AI Analysis 按鈕是灰的，而且沒說為什麼
它要四個條件都滿足：選了專案、指定了 MR、 勾了除錯就要填存放目錄、選了手動單號就要填單號。 不說明原因是刻意的，與工具裡另一個功能同一個作法。
MR 清單空的
按重新整理。另外，換專案或改查詢條件都會清空清單 —— 否則你看到的是上一個專案的 MR，按下去分析的卻是現在選的那個。
報告第一行說「未經過 AI」
AI 端點還沒設定。這時第三步不會失敗，而是產出替代內容 並在第一行講明白 —— 這樣還沒有端點的時候整條流程仍然跑得完、驗得到。
報告裡的檔案比 MR 實際改的少很多
正常，而且「分析涵蓋範圍」那一段會告訴你少在哪裡： 差異太大送不進去、你的設定把它排除了、或是送進去了但 AI 沒回報。 三種各自有不同的處理方式。

常見問題

大家問過的

跑一次要多久？
第 3 步問 AI 是分鐘級，其餘每一步幾秒。整體取決於這支 MR 改了多少東西。
會花錢嗎？
只有第 3 步會呼叫 AI 服務。其餘四步只跟 GitLab 與 JIRA 往來，不花錢。
報告會自動貼回 MR 嗎？
不會。它只顯示在結果視窗，要不要貼回去由你決定。
貼回去也不會愈疊愈長 —— 下一輪的第 1 步會把上一輪的 AI 分析那一段扣掉。
可以一次分析好幾支 MR 嗎？
不行，一次一支。Repository 與 Merge Request 兩個清單都是單選。
跑到一半可以停嗎？
可以，處理中對話框上有取消。取消之後畫面完全不動 —— 沒有半套結果需要你收拾，後續步驟也不會啟動。
同一支 MR 可以重跑嗎？
可以。重跑就是再完整跑一次五步，所以會再花一次 AI 的錢。
沒有 JIRA 單號可以用嗎？
可以。JIRA Key 選 None，第 4 步就不會去找 code review，報告裡少那一段而已。
我的程式碼會被送到哪裡？
第 3 步會把差異送到你在 AI Mode 選的那個端點。其餘步驟只跟 GitLab 與 JIRA 往來。
選一個專案 → 按重新整理 → 點一支 MR → 按 AI Analysis。
其餘的它自己跑，跑完給你一份可以直接貼回去的報告。
