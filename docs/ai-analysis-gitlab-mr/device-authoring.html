開始

三件事

1
複製範本，改成你的名字
cp -r device/_template device/ssd
目錄名會被當成模組名 import，所以必須是合法的 Python 識別字： 小寫英數與底線、不以數字開頭。ssd_gen4 可以，ssd-gen4 不行。
2
在 __init__.py 宣告 VERSION
這一個一定要有，沒宣告會直接失敗。 它會印在報告末尾（Device: ssd 1.2）。改了產出方式就把它往上加 —— 不加的話，新舊兩套邏輯產生的報告會帶同一個版本號。
3
刪掉你不想覆寫的那幾支
五支全都是選用的。只想改報告版面？那就只留 merge_to_md.py， 其餘四支刪掉 —— 缺的會自動用 default 的。
# 只想改報告版面的 device，合法而且推薦長這樣： device/ssd/ __init__.py VERSION = "1.0" ← 必要 merge_to_md.py ← 你唯一要寫的 # 其餘四支不存在，自動落回 default/
不要改 device/default/
它是所有 device 的共同後備：每一支沒有被覆寫的擴充腳本 都會落到它身上，別條產品線的也一樣。改 default/ 等於同時改掉所有人的行為。
要不一樣的做法，在自己的目錄裡放一支同名檔覆寫它就好。

回退是逐支的

不是「整個 device 找不到就用 default」，是一支一支找

PPS_DEVICE=ssd，這筆 MR 的種類是 bug summary.py（因種類而異，找三層） ① device/ssd/bug/summary.py ← 有就用它，結束 ② device/ssd/summary.py ← 再找這裡 ③ device/default/summary.py ← 最後的後備 jira_key.py（不因種類而異，找兩層） ① device/ssd/jira_key.py ② device/default/jira_key.py PPS_DEVICE=sdd（打錯字） ✗ 直接失敗，訊息列出目前認得哪些 device
認不得的 device 是錯誤，不是退回 default
打錯字或忘記部署時，靜默改用通用邏輯會產出一份用錯邏輯、 而且每一步都回報成功的報告 —— 那比直接失敗糟得多。
但認不得的種類相反，它視同「沒有種類」
種類是 MR 作者在標題裡打的字，不是部署問題。 要讓它變成錯誤的話，在 __init__.py 宣告 STRICT_TYPE = True。

常見問題

開始寫之前會想問的

怎麼新增一個 device？
照這個順序
1
複製範本：cp -r device/_template device/ssd
目錄名就是 device 名，必須是合法識別字（ssd_gen4 可以，ssd-gen4 不行）
2
在 __init__.py 宣告 VERSION —— 沒有就直接失敗
3
只留你要覆寫的擴充腳本，其餘刪掉 —— 缺的各自用 default 的
4
設定檔 PPS_Device 填名字 （CI 設環境變數 PPS_DEVICE）
5
跑一次，看報告末尾出處的 Device 欄位

⚠️ 不要改 device/default/ —— 那是所有 device 的共同 後備，改它等於改掉所有產品線。要不一樣的做法，在自己的目錄裡覆寫。

沒放的擴充腳本會用哪一份？
規則只有一條：同一支擴充腳本有好幾份時，離你近的那份贏。 假設 PPS_DEVICE=ssd，這一筆 MR 的標題是 [PPS-1234][Bug] 修正重試上限，擷取出來的種類是 bug：

近 ←——————————————————————→ 遠

步驟 device/ssd/bug/ device/ssd/ device/default/
②jira_key 不看種類 — jira_key.py
②mr_type 不看種類 — mr_type.py
③summary — summary.py summary.py
④parse_code_review 不看種類 — parse_code_review.py
⑤merge_to_md merge_to_md.py — merge_to_md.py

每一列由左往右找，第一個有檔案的就用， 後面的不再看。五列各走各的 —— 覆寫一支不會把其他四支一起帶走。

左邊那一欄只有 ③ ⑤ 用得到。jira_key、 mr_type 跑在種類被決定之前（bug 正是 mr_type 判出來的），parse_code_review 則是刻意不分種類 —— 審閱報告的格式是 device 的屬性。

⚠️ 表上沒有 default/bug/ 這一欄， 也永遠不會有 —— 種類名稱是各 device 自己的字彙，你的 bug 與別條產品線的 bug 不保證是同一件事。
